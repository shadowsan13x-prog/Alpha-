ALPHA — بوت Messenger مستقل
المطور: KAI

هذه النسخة تشغّل البوت مباشرة، ولا تحتوي على لوحة ويب أو واجهة إدارة عبر المتصفح أو خادم Telegram؛ وتبقى أوامر ALPHA داخل Messenger فقط.

التجهيز
1) ثبّت Node.js 24 أو أحدث.
2) انسخ config.example.json إلى config.json.
3) ضع معرّف حساب المالك الأساسي في DEV_ID. ضع أي مطورين أساسيين إضافيين في DEV_IDS.
4) أضف ملف جلسة Facebook باسم appState.json في جذر المشروع. ملف الجلسة غير مرفق داخل الحزمة لحماية الحساب.
5) نفّذ npm install ثم npm start.

تشغيل Railway / Docker
- أمر التشغيل: npm start
- يستمع فحص الصحة على PORT الذي توفره المنصة.
- استخدم تخزيناً دائماً لملفات config.json وappState.json وdata.json.
- لا ترفع appState.json أو config.json أو مفاتيح API إلى مستودع عام.

صلاحيات المطورين
- DEV_ID هو المالك الأساسي الوحيد الذي يستطيع إضافة المطورين أو حذفهم.
- بقية المطورين يستطيعون عرض القائمة باستخدام !dev ls.
- المطورون المضافون بواسطة !dev add يُحفظون في data.json ويُعتمدون في صلاحيات البوت والحماية.
- لا يمكن حذف المالك أو أي مطور أساسي معرف في config.json بواسطة أمر dev.
- أوامر المطور تظل محمية حتى عند تفعيل الوضع العام.

الأوامر والاختصارات
- !help / !h — عرض القائمة.
- !اسم / !nm — تغيير اسم المجموعة وحفظه.
- !كنيات / !nk — إدارة الكنيات المحفوظة.
- !بيس / !bs — إرسال رسالة متكررة بفاصل زمني.
- !محرك / !eng — تشغيل محركات الإرسال.
- !angel / !ag — إرسال نص تلقائي بفواصل زمنية (للمطورين فقط).
- !aut / !au — الرد تلقائياً على الرسائل البشرية الجديدة في المحادثة (للمطورين فقط).
- !حذف / !del — حذف رسالة البوت التي تم الرد عليها.
- !خروج / !lv — إخراج البوت من المجموعة.
- !صورة / !av — تغيير صورة حساب البوت.
- !بايو / !bio — تغيير وصف حساب البوت.
- !فتح / !op — فتح استخدام الأوامر للجميع.
- !قفل / !cl — قصر استخدام الأوامر على المطورين.
- !التحكم / !ctl — أدوات التحكم بالمحادثات من داخل Messenger، ويمكنه تشغيل الأوامر في المحادثة المختارة.
- !تحميل / !dl — إعداد التحميل التلقائي (يتطلب FASTSAVER_API_KEY).
- !جلسة / !ss — عرض حالة ALPHA ومعلومات التشغيل.
- !uptime / !up — عرض إحصائيات التشغيل.
- !command / !cmd — فحص وإعادة تحميل ملفات الأوامر.
- !dev / !dv — إدارة قائمة المطورين.

صيغة أمر المطور
- !dev add 123456789 أو بالرد على رسالة الشخص.
- !dev rm 123456789 أو بالرد على رسالة الشخص.
- !dev ls لعرض القائمة.

ملاحظات
- البادئة الافتراضية هي ! ويمكن تغييرها من data.json إذا كنت تدير الملف يدوياً.
- ملف appState.json وconfig.json غير مضمنين في الحزمة؛ جهّزهما قبل التشغيل.
- الاختبارات: npm test

أمر Angel (للمطورين فقط)
- !ag [النص] [الفاصل] — إرسال نص تلقائي.
- يرسل النص مباشرة أولاً مثل بيس، ثم يكرره حسب الفاصل دون رسالة تشغيل إضافية.
- الوحدات: s ثوانٍ، m دقائق، h ساعات، d أيام.
- أقل فاصل 5 ثوانٍ، وأقصى فاصل 7 أيام.
- !ag off — إيقاف Angel في المحادثة الحالية.
- !ag off all — إيقاف جميع مهام Angel؛ للمالك الأساسي فقط.

أمر Aut (للمطورين فقط)
- !au [النص] — الرد بالنص المحدد على الرسائل البشرية الجديدة.
- يحافظ على الأسطر الجديدة في النص مثل أمر بيس.
- يفحص سجل المحادثة كل 40 ثانية، ويختار أحدث رسالة بشرية جديدة فقط.
- يُظهر مؤشر الكتابة 3 ثوانٍ قبل إرسال الرد.
- بعد 16 دقيقة دون رسالة بشرية، يرسل الرسالة الختامية مرة واحدة ثم يغادر البوت المجموعة.
- !au off — إيقاف Aut في المحادثة الحالية.
- !au off all — إيقاف جميع المهام؛ للمالك الأساسي فقط.
- يمكن تشغيله عن بُعد من التحكم: !التحكم تنفيذ aut [النص]
- يجب اختيار المحادثة أولاً من قائمة !التحكم، ثم تنفيذ الأمر أعلاه.
